# -Travel--Aurelia-Travel-prototype-work
A luxury travel website built with React and Vite, showcasing bespoke journeys, elegant design, and seamless navigation for premium travel experiences.

## Password reset

The sign-in page includes a “Forgot password?” flow with request and new-password screens. It uses the backend `/api/auth/forgot-password` and `/api/auth/reset-password` endpoints; the backend must be configured with SMTP to deliver reset emails.
